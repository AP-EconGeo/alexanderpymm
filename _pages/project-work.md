Alongside my research, I also work on the operational side of funded project delivery, spanning project management and administration across the grant lifecycle. I'm particularly interested in finding more efficient and effective ways of delivering this work with the use of modern technologies and digital workflows.

This page is a collection of recent projects I've worked on to accomplish that.

* [Practical Trip Costing Planner (Excel, Costing Tool)]({{ site.baseurl }}/files/Trip_cost_estimator_-_Alexander_Pymm.xlsx) - The first small project is a practical trip costing planner, drawing on current HMRC scale rates and FX data to provide quick project estimates for accommodation, subsistence and travel costs with minimal user input. This has already proven a significant time-saver for routine route-planning work and overseas reimbursement estimates on various projects.

* [SHOC 2.0 UKRI - Budget vs Actuals Illustrative Dashboard (Excel, Dashboard with Power Query Functionality)]({{ site.baseurl }}/files/SHOC2_Budget_vs_Actuals_Dashboard.xlsx) - One of my recent projects is a Budget-vs-Actuals project dashboard, which, once linked up with appropriate internal systems, would import an organisation's transaction data through Power Query scripts, tracking them against a funder budget as entries are added. This particular version is built around a hypothetical SHOC 2.0 budget, using a standard UKRI-style fEC structure and a fictional set of transactions. To be clear: all of the contents, including the basis of the project itself, is entirely fictional and has not been endorsed by any potentially relevant parties.
